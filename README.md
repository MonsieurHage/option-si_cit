# SI / CIT en seconde — Institution Saint Jean Douai

Ouvrir `index.html` dans un navigateur. La présentation comporte 12 diapositives, un sommaire, des activités à explorer et un quiz. Les flèches du clavier permettent de naviguer.

## Logos autorisés

Le logo rond `assets/brand/logo-couleur.webp` est le seul logo affiché. Il figure dans le cartouche blanc en haut à gauche de chaque diapositive.

## Publier sur GitHub Pages

1. Créer un dépôt public, par exemple `presentation-si-cit`.
2. Déposer `index.html`, `assets/` et `README.md` à la racine du dépôt en conservant l’arborescence.
3. Dans **Settings → Pages**, choisir **Deploy from a branch**, la branche `main` et le dossier `/(root)`, puis cliquer sur **Save**.
4. Une fois le déploiement terminé, partager l’URL affichée dans **Settings → Pages**, généralement `https://<compte>.github.io/presentation-si-cit/`.
